## 🚀 Pasos realizados
 
1. Se hizo **fork** del repositorio original a esta cuenta.
2. Se clonó el fork de forma local:
```bash
   git clone https://github.com/tu_usuario/tu_repositorio.git
```
3. Se agregó el repositorio original como remoto (`upstream`):
```bash
   git remote add upstream https://github.com/borissalleg/practica-git-poo.git
```
4. Se creó una rama de prueba:
```bash
   git checkout -b prueba-fork
```
5. Se realizaron cambios y se subieron al fork:
```bash
   git add .
   git commit -m "Prueba de fork"
   git push origin prueba-fork
```
6. (Opcional) Se abrió un **Pull Request** hacia el repositorio original.
